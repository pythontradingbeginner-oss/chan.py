# 青派缠论 RB 策略下一阶段对话上下文

日期：2026-08-14  
主题：Alpha 来源、退出机制、市场状态适配与外部稳健性验证  
基线：以包含本文件的最新 checkpoint commit 为准；进入新对话后先运行
`git rev-parse HEAD` 和 `git status --short` 核对。

## 1. 新对话目标

本阶段回到交易策略本身，在全局结构下研究三件事：

1. 当前青派缠论信号的可交易 Alpha 究竟来自哪里，哪些 BSP、结构、级别、方向或确认
   条件具有稳定的条件期望；
2. 当前退出机制如何影响收益分布，亏损来自错误入场、止损位置、退出延迟、利润回吐，
   还是合约换月与成本；
3. 策略对趋势、震荡、波动率、流动性、交易时段和换月阶段是否存在稳定差异，以及
   市场状态适配应当用于解释、过滤、仓位还是退出。

更长历史、跨品种和跨周期是后续外部稳健性验证，不是第一轮参数搜索工具。

和 vn.py 接入。不要为了改策略重写缠论核心；先确认结构语义，再在策略和研究层修改。

## 5. 研究分层

### 5.1 第一层：原始 Alpha 与退出机制

使用 B0 观察口径：四个账户状态门控保持 observe，硬前提仍 enforce。目的不是生产模拟，
而是让全部合法信号路径可见，避免连亏、累计亏损或回撤门控把信号样本截断。

每个候选改动必须回答：

- 它改变的是候选 setup、确认、入场价格、退出，还是风险状态；
- 交易数量为何变化；
- 改善来自胜率、平均盈利、平均亏损、尾部亏损、持有时间还是成本；
- 效果集中在哪些年份、fold、BSP、方向、合约 epoch 和市场状态；
- 是否存在 look-ahead、选择偏差或结束窗口强平污染。

### 5.2 第二层：风险交互

候选机制在 B0 下通过后，再用同一冻结参数运行 CURRENT_ENFORCED 和 B1，区分：

- Alpha/退出机制本身的变化；
- 风险门控对交易路径的删选；
- 回撤、日损、累计亏损和连亏状态对结果的二阶影响。

Option D 此时只可作为冻结后的附加敏感性诊断，不参与候选筛选或参数优化。

### 5.3 第三层：外部稳健性

机制通过前两层后，才扩展：

- 更早、更长的 RB 历史；
- 不同黑色系或非黑色系品种；
- 5m、30m、60m 等周期；
- 不同手续费、滑点、涨跌停和换月假设。

外部数据用于尝试推翻假设。不得看到结果后继续改阈值，再把同一数据称为 OOS。

## 6. 第一轮必须完成的审计

在修改策略前，先产出一份“Alpha-退出-市场状态全局机制图”，至少覆盖：

1. 信号生成链：K 线包含处理 → 分形 → 笔 → 线段 → 中枢 → BSP → 青派过滤 →
   多级别/动量确认 → `TradeIntent`；
2. 每个 BSP 类型、grade、方向和 setup family 的样本数、入场后 MFE/MAE、最终 PnL、
   持有 bars 与退出原因；
3. 退出路径：结构止损、执行止损、超时、利润保护、信号反转、换月、end-of-data；
4. 市场状态候选：趋势/震荡、波动率、成交量/流动性、日夜盘、换月距离、价格跳变；
5. 交互矩阵：哪些入场类型依赖哪些退出和状态，哪些变量只是同一结构的重复代理；
6. 当前审计字段是否足够；若不足，只先补观测字段，不改变交易决策。

第一轮输出应先是事实地图、缺口和可证伪假设清单，不应直接给出“最佳参数”。

## 7. 候选实验优先级

建议按以下顺序提出假设，每次只改变一个机制：

1. **Alpha 归因**：识别正负贡献的 BSP/setup/方向/阶段，先判断是否确有信号优势；
2. **退出归因**：用 MFE/MAE 和退出原因判断，是止损、利润回吐还是持有期限造成损失；
3. **市场状态解释**：验证状态变量是否具有跨 fold 的条件差异，而非仅拟合年份；
4. **机制改动**：从最强、最可解释的单一假设开始实现；
5. **冻结后验证**：连续流、walk-forward、年份/合约切片、成本压力和外部样本。

每个实验建立独立 hypothesis ID，预先写明：机制、唯一变量、对照组、预期方向、失败
条件、所需字段和验收指标。禁止同时修改入场、退出、状态过滤和风险门控。

## 8. 验收指标

不能只看总净点数。至少同时报告：

- 样本数、交易数、暴露时间和拒绝原因；
- 每笔期望、profit factor、胜率、平均盈亏、盈亏比；
- 最大回撤及其金额/点数/百分比口径；
- PnL、MFE、MAE 和持有期分布及尾部；
- 年份、fold、BSP、方向、setup、session、合约 epoch、市场状态分层；
- 参数邻域稳定性和交易成本压力；
- 与冻结基线的决策、成交、身份和配置 parity。

候选机制若只改善聚合 PnL，却显著减少样本、集中于单一年份/状态、依赖少数异常交易，
或在 fold-reset 中方向不稳定，应判为未通过，而不是继续微调。
