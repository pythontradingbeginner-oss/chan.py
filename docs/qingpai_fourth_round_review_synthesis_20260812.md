# 青派第四轮独立审查综合分析（2026-08-12）

## 审查范围校正

三份附件并非同一层级的三票独立审查：

| 附件 | 实际审查对象 | 对当前 OPEN-005 的直接证据权重 |
| --- | --- | --- |
| Gemini 4A | P0/G06 实施与重跑结果 | 高 |
| DeepSeek 4B | 2026-08-10 全局基线文档及当前源码 | 中；主要是文档和架构复核 |
| GLM 4C | 2026-08-10 全局基线文档及当前源码 | 中；主要是文档时效性复核 |

因此不能把三份附件解释为三家 AI 一致支持某一种连续亏损恢复政策。只有
Gemini 明确裁决了 OPEN-005；DeepSeek 和 GLM 的主要结论是全局基线准确但已出现
版本时间差。

2. 与 2026-08-10 连续基线相比，3658 条决策、183 条执行决策和 10 笔交易行为
   完全一致；P0 没有混入入口或退出规则变化。
3. `daily_loss_limit` 已按 RB 交易日恢复。首次后续风险拒绝记录中
   `daily_realized=0`，阻断来自 `max_consecutive_losses=5`。
4. 连续全历史的 173 次风险拒绝全部来自不可达恢复的连续亏损吸收态。
5. Fold-reset 的 +618 点只证明风险状态边界高度敏感；由于有 2 条
   continuous-only 决策（其中 1 条 accepted），不能解释为纯风险复位收益。
6. Setup 状态机、连续亏损恢复和策略经济性实验必须分轮实施和重跑。

## 对 Gemini OPEN-005 建议的复核

### 可采纳部分

- 不应继续保留“达到 5 亏后只能靠一笔盈利恢复、但又禁止所有新交易”的不可达状态。
- 不应凭当前已看过的数据直接选择任意 `N` 天、`N` 根 bar 或影子盈利作为正式恢复条件。
- 风险恢复必须由显式状态转换驱动，并进入持久化和审计，不应继续依赖隐式计数器副作用。

### 不能直接采纳的部分

#### 1. “单交易日 5 连亏”在当前频率下等价于关闭门控

对新回放产物按 RB 交易日重新汇总：

| 产物 | 最大单日平仓数 | 最大单日亏损平仓数 | 最大单日连续亏损 |
| --- | ---: | ---: | ---: |
| 连续全历史 10 笔 | 3 | 3 | 3 |
| Fold-reset 86 笔 | 3 | 2 | 2 |

因此将阈值 5 的作用域改为单交易日，在 2018-2026 已观察成交轨迹中一次也不会
触发，其已观察保护作用为零。由于政策变化后的反事实成交路径可能继续改变后续
持仓与信号，是否与完全禁用门控严格等价仍须独立重跑；但它不能被包装成已有证据
支持的最优正式政策。

#### 2. “零凭空参数”不成立

日内 scope 本身就是新增行为选择，阈值 5 也仍是参数。没有额外的冷却数字，不代表
没有策略假设或拟合风险。

#### 3. 人工复位不是工程上不可行

人工复位作为无人值守研究政策会使长回放失去后续交易样本，但作为实盘安全停机
latch 完全合理。必须先区分：该门控究竟是账户安全熔断器，还是策略状态/市场
适应性过滤器。两类职责不应共用一个模糊计数器。

#### 4. 触发时点表述需修正

连续第 5 笔亏损在 2018-08-10 10:00 平仓后形成；2018-08-24 夜盘是其后第一条
accepted 信号被拒绝的时点，不是第 5 笔亏损的成交时点。

#### 5. “收益完全由风控而非 BSP 主导”证据不足

当前证据只能说明“已观察到的成交集合被风险状态边界主导”。Fold-reset 不是严格
决策 parity，且没有提供冻结的新样本，所以不能据此判断 BSP 是否具有稳定 alpha。

#### 6. 契约 ID 冲突

Gemini 建议新增的 `QP-RISK-002` 已被现有规则契约用于“仓位风险基数”，不得复用。
新的恢复规则应使用未占用 ID，并保留版本迁移记录。

#### 7. 重跑顺序与其因果隔离原则矛盾

OPEN-005 实施后必须先单独重跑；不能紧接着实施 P1，再用一次合并重跑同时解释
风险恢复和 Setup 状态机的效果。

## 对 DeepSeek 与 GLM 意见的复核

### 应采纳的文档修订

1. 2026-08-10 全局基线应增加明确的 `as-of` 代码状态，并链接本次 P0/G06
   实施报告；其中“日切依赖 fill”和“CTA 不逐 bar 观察权益”已对当前工作区过时。
2. G01 章节补充 Rulebook 第 11 节引用，明确“走势分类暂不做统一硬门槛”是冻结默认，
   不是遗漏。
3. 修改影响矩阵增加 `_consumed_keys` 身份粒度一行，联动重验 G03/G08、重复入场、
   连亏计数和三端 parity。
4. 生命周期不变量应明确作用域：结构和不可变记录在单次运行内 append-only；若要求
   跨重启不可回写，还需要持久化审计日志契约。
5. 入场顺序可把可选 DC/OBV/Volume `FilterPipeline` 与 `RiskManager` 分开写清；实际
   回测执行顺序为 filter 在前、risk approve 在后。严格配置未启用该 filter，因此
   这是文档精度问题，不是本轮成交集合的遗漏机制。

### 不应转化为当前策略改动的内容

- DeepSeek 与 GLM 对底层对象链、双止损、时点和价格域的复核主要确认旧基线准确，
  不构成新的策略修改理由。
- GLM 曾提出的实盘 `price_adjustment` parity 疑虑已在其自身复核中撤销：实盘输入
  是真实合约价，回测输入是调整连续价，两端需要不同的翻译入口。
- 这些审查没有独立支持 Gemini 的“按日清零连续亏损”建议。

## OPEN-005 下一轮候选状态机

在人工裁决前，不修改当前行为。下一轮应并列审查以下互斥政策：

### A. Manual Latch

- 达限后人工复位。
- 适合作为实盘账户安全停机，不适合作为无人值守策略过滤器。

### B. Gate Disabled Baseline

- 禁用策略层连续亏损门控，仅保留日亏、累计亏损和最大回撤。
- 用于测量信号/退出链在没有该门控时的完整行为，不默认用于生产。

### C. Intraday Reset

- 连亏计数随 RB 交易日清零。
- 在当前阈值 5 的已观察历史轨迹中没有触发，应如实标记并重跑检验其是否与 B
  形成反事实差异，不能预先宣称具有保护作用。

### D. Next-Session Probe（建议进入交叉审查）

状态转换：

```text
ACTIVE
  -- loss streak reaches limit --> PAUSED_UNTIL_NEXT_SESSION
PAUSED_UNTIL_NEXT_SESSION
  -- session advances --> PROBE_AVAILABLE
PROBE_AVAILABLE
  -- one probe wins --> ACTIVE, streak=0
  -- one probe loses --> PAUSED_UNTIL_NEXT_SESSION, streak retained
```

它保留跨日连续亏损含义，消除不可达恢复，不需要影子成交，也不需要凭空选择多日
冷却长度。其代价是引入“每个交易日最多一笔 probe”的明确策略语义，仍须人工与
其他 AI 交叉审查，不能作为工程默认直接实施。

## 建议顺序

1. 先修订文档版本与影响矩阵，不改变策略。
2. 对 A-D 四种互斥状态机做规则层裁决；同时分别定义 `max_loss_points` 和
   `max_drawdown_pct` 是 manual latch、永久停机还是有恢复带。
3. 冻结 OPEN-005 机器契约、状态持久化字段和测试矩阵。
4. 只实施 OPEN-005，完成一次独立的连续/fold-reset 重跑与旧决策 parity。
5. OPEN-005 结论稳定后，再实施 P1 G03/G08，并进行第二次独立重跑。
6. 最后才研究 G01/G02/G05/G07 的经济性。
